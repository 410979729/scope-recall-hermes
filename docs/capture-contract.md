# 来源捕获边界

捕获在同一 SQLite 事务提交来源、中文二元词/完整标识词法投影、唯一 consolidate/embed 工作项。辅助模型可以完全停用；原文检索不依赖它们。来源不是 active Claim；capture 回执的 mutation 为 none，只有新来源在捕获时直接更正或确认了一条主张时为 revised。候选与正式主张的碰撞/晋升规则由同一主张存储实现。

捕获复用 secret_patterns 的统一 Unicode/凭据扫描和 capture_filters 的遮罩及二进制传输识别。在生成来源指纹、写库、建立词项或工作前，检测出的凭据值替换为 [REDACTED_SECRET]，遮罩跨度之外的文字保持原样，行内值的边界无法确定时遮罩到行尾；prepared capture 与回执的 masked_secret_count 报告分段前合并跨度的替换次数。身份及引用字段含秘密时拒绝，这些字段不改写；遮罩后仍有秘密、整段只能被占位符替代、私钥块、没有闭合的三引号字面量、无法精确映射或安全分离的跨行值也拒绝。原始段落的缩进、换行和其余标点保持；遮罩记入 secret_values_masked，去掉 base64/附件缓存标记记入 transport_payload_omitted，两者都导致 partial 与 capture_gaps。“好/收到”等 trivial 过滤不适用于来源发生记录，因为真实的重复发言要保留。

协议入站总量由 2 MiB 边界限制，超长正文按至多 65,536 字符稳定分段，每个字符恰好保留一次；组键来自宿主发生键，不能由正文哈希生成。宿主已经分段的材料保留其组、序号、总数与截断信息，过大的嵌套段拒绝，不伪造两个层次的序号。保存一批自动分段是一个原子事务；宿主逐段送达时，缺段可见为 source_segments_incomplete。修订变短不会把旧版多余尾段当作当前来源返回。

同键同版本重放不改变首次记录时间、epoch、词法或工作状态。回执读取实际投影状态；已有来源却没有索引时，不返回 ready，也不在重放或查询时暗中修复。内容、origin、发生时间或可信范围冲突返回 conflict。history 可以展开旧来源；普通原文检索只返回来源组的最新修订。原文检索结果仍不是“当前真实事实”。
