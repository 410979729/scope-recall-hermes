# 3.1.0.dev2 全面审计与优化

本次以交付过的 `3.1.0.dev1` 为基线，先核对 117 个运行文件和原 wheel 哈希，再在独立 worktree 审计。基线提交为 `2c4d177b2f4e1e71ac06de0100790ab2795ff0fd`。这份文档描述本轮变更；交付目录的验收回执记录实际构建、测试和安装结果。

## 修复的主要问题

| 范围 | 之前的问题 | 新行为 |
| --- | --- | --- |
| 删除授权 | “不要忘记”以及引用、条件句可能被当成删除命令 | 保守拒绝非直接删除授权，保留原记忆 |
| 恢复并发 | 导出删除检查点后，写入可能抢在恢复标记前提交 | writer 事务内重新核对检查点并建立恢复栅栏；已打开的连接获得事务后再次核对栅栏 |
| 恢复后清理 | 旧快照恢复出附件或向量，但沿用已清除回执且没有清理任务 | 重置物理层盘点状态，按原权限重建清理任务并使旧 lease 失效 |
| 文件与迁移 | resolve 提前消除了 junction 证据；immutable 读取可能遗漏 WAL 中的旧数据 | 校验原路径的祖先链；排他创建输出；拒绝非空 WAL/journal 的迁移输入，要求一致快照 |
| 记忆身份 | 名称子串碰撞、当前 project_id 免来源证明可能导致错误归属 | 稳定 ASCII ID 完整匹配；人物/项目仍需来源证明，保留已有别名的独立证明 |
| 否定与条件 | 否定条件、否定值、禁止继续任务可能被反向解释 | 保留所在语句的否定/条件；不会把“不要继续”改成打开任务 |
| 当前版本 | 未来生效的新版本遮住仍有效旧版；环境变化后仍使用旧进度 | 读取当前有效版本；未经重新验证的旧环境进度退出自动/当前召回 |
| 上下文预算 | 背景记忆排序可能抢先消耗问题证据预算 | 问题证据优先，背景装不下则省略，仍不冒充答案 |
| 后台与权限 | 不同授权会话的尾随唤醒丢失；只读会话结束启动 writer | 按完全相同的权限集合有界合并；锁等待受原期限约束；只读退出不启动写入 |
| 长会话 | 观察/结果缓存无界，失败缓存被旧会话占满，淘汰后回放时间变化 | 有限缓存；按原身份处理已有重试；从 SQLite 读取首次时间，内容仍过冲突检查 |
| 费用与恢复 | 缺少凭据占用模型配额；HTTP 临时错误类型无法冷却恢复；结算等待超过预算 | 提前检查凭据；识别安全的 HTTP 临时错误；结算与重试不突破账本和时间边界 |
| 诊断 | import 成功被当成安装正确；重试刷新积压年龄；延后来源无总数 | 报告实际包版本/位置；保留原始待办年龄；汇总当前可见 source_only/deferred 来源分段 |
| 长文本 | 正则从每个字符重复扫描连续长文本，导致捕获超时 | 限定完整 token 的起点，保留过滤与索引语义，验证长中文分段与回放 |

详细 admission 统计只在显式状态和 doctor 中执行，不给每个内部 epoch/队列检查添加来源 JSON 全表扫描。SQLite schema 保持 1105，无新数据格式升级。

## 验证如何解释

采用反例、受影响的既有契约、真实 SQLite 事务/线程栅栏、真实 Windows junction 和安装包核对。用例按独立身份去重，保存首次失败与复验，不把多次执行相加成虚高总数；未运行仓库全量测试。模型错误与账本测试使用合成 transport，不消耗真实 API。

本轮没有重新声称通过真实模型语义准确率、长期负载或真实宿主全部行为。上一候选的真实模型证据只属于上一候选；本次制品的独立安装回执另行记录。恢复向量清理验证了重新排队及端口调用，未把合成向量端口当成真实 Lance 擦除证明。

## 仍保留的能力边界与后续顺序

1. **真实实例切换与旧库迁移验收**：由部署任务基于冻结候选完成，特别核对天枢/玉衡的专用 user/session、retained scopes 和旧库映射。本任务不操作生产库。
2. **真实语义与长期质量基线**：需要有代表性的真实任务、费用上限和持续时间，才能评价长期召回、误记/漏记、自动加工积压。局部合成测试不能证明“世界顶级”或长期无人值守表现。
3. **复杂中文实体、指代与条件**：当前按来源保守匹配，无法保证任意中文姓名、多人指代、复杂否定和转述都能理解。拒绝无证据归属比自动补出身份更符合记忆真实性；进一步能力应以明确评测驱动。
4. **候选覆盖与空闲恢复**：背景候选仍有 24 条扫描边界；没有新常驻服务，主机没有后续活动时不会无限自动重唤醒。容量、凭据或预算耗尽仍有明确缺口，不假装已处理。
5. **删除与文件系统边界**：保证插件权限与逻辑阻断，不能宣称擦除系统历史、第三方备份或物理介质；也不是阻挡同权限管理员替换整套数据与回执的沙箱。
6. **Windows 路径长度**：本机安装复用测试在深层临时目录下出现 264 字符路径失败；改用同一 TEST 根下的短目录后通过。应使用短的安装/备份根目录，本轮没有把这个结果宣称为任意长路径兼容。

未引入人工 Journal 审批或无限模型自愈。后续优先完成真实部署与有费用边界的质量观察，再根据实际失败增加功能。
