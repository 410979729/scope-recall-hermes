# Claim 时间与更正边界

`core/claims.py` 是纯资格与时间规则，`core/claim_storage.py` 在存储的事务对象内操作唯一真值库，`core/mutate.py` 负责用例，不持有模型调用。

## 身份与来源

Claim slot 由 scope、project、branch、kind、subject、predicate 及条件集合精确组成。语义相似度和别名不合并身份。不同条件生成不同 slot；读取允许已授权的全局对象，修改要求目标与当前项目/分支精确匹配。来源与主张的 scope/project/branch 必须一致，提交前核验来源组的最新版本。候选与现有 active 断言完全相同时返回 duplicate，不改 head、有效时间、生命周期、epoch、证据或工作队列。

原文证据跨度必须命中真实来源的指定版本。摘要、宿主内容和记忆回注可保留 derived_from 关系并追溯、去重根来源，但其文字不能借原始人类来源取得资格。资格判断要求原根上的真实跨度；角色标签不足以证明人类来源。`ImportProvenance` 属于受信运行时上下文，不属于模型 DTO；授权导入器验证清单后提供清单 SHA 和最多 200 个具体 SourceEvent 指纹。存储核验原始来源类别及包含记录键、版本、时间、原文的精确指纹，并将清单指纹纳入不可变事件重放身份。仅有 imported/source_original_origin 标签的资料保持未验证。

资格规则保守保留 proposed。证据所在句及关联前置标题参与否定、假设、条件和时间判断，不能通过裁掉“假设/不”晋升，也不因另一个无关句子的假设降级。在条件或假设下说的断言（“要是值班表调整，告警频道是 X”）须把条件写入 conditions，成为另一个 slot；丢掉条件则保持 proposed。相同短引文有过多不确定位置时拒绝。未知、缺段、不完整来源不能独自建立 active。procedure 的方法步骤、反例字段和核验依据受来源限制，在条件或假设下说的认可不算认可；intention 的完成/取消需要对应来源，不因助手提醒、回注或条件句而完成或取消；未解析的 alias 目标保持 proposed。

否认是取值以完整否定结构开头的 fact 或 preference：否定词连同它所否定的内容（“不是 X”“不吃辣”“从不抽烟”“不再用 X”“not X”“isn't X”“don't have a car”“no longer uses X”），或厌恶（“讨厌 X”“受不了 X”“can't stand X”）。只是以否定字开头的固定说法不是否认（“不错”“不过”“没问题”“不客气”“不同意”“不知道”“not bad”“not only … but”“don't know”“not sure”），问句也不是（“isn't it X?”）。写入时否认与 slot 当前的有效取值比较。否认的是别的取值时（当前 Jenkins，说“CI 不是 CircleCI”；当前偏好 bash，说“不喜欢 PowerShell”），它保持 proposed（`denial_of_another_value`），留在 head 旁边，不推进 head，重复或第二个来源也不能使其晋升。本人的 slot，即 preference 或主体是所引来源本人的 fact：slot 没有有效取值时，否认就是答案，照常资格判断（“我不吃辣”“I don't have a car”；本人的否定自述把动词留在取值里，无法排出主体、关系、取值的事实框架，所以与偏好一样以绑定到本人分句为准）；否认的正是当前取值时（当前“爱吃辣”，后来说“我现在不吃辣了”），它是一次更新，按通常的先后规则取代当前取值。主体是其他任何事物的 fact，否认只说 slot 不是什么，从来不是 slot 的取值：slot 没有有效取值时它保持 proposed（`denial_not_a_value`）；否认的正是当前取值、且按先后规则本可取代它时（当前 Jenkins，后来说“TEST-project 的 CI 不再是 Jenkins”），当前取值在否认的时间结束，用已有的撤回机制：以否认的原话为证据写入撤回版本作为 head（`value_denied`），历史全部保留，否认本身留作 head 旁边的 proposed，于是问这个 slot 得不到当前取值。是否同一取值：去掉否定词和其后的“了”“any more”等时间词，与当前取值按存储比较取值的方式归一（NFKC、不分大小写）后逐词比较：一个中文字算一个词，标识符连同其中的 .、-、_、/ 和开头的 #、@ 整体算一个词（v3.1、#ops-pager），拉丁词取事实门对谓词词形所用的词干，冠词不算词。当前取值连续包含否认所否认的全部（去掉开头的系词）时，否认的就是它（“不是周三”否认“周三下午”，“不吃辣”否认“爱吃辣”）；否认在当前取值本身之前只多出结构里的喜好、使用或动作动词时也是（“不喜欢用 PowerShell”否认“PowerShell”，“不喜欢喝红茶”否认“红茶”）。更长的否认不否认更短的取值，多出的词收窄了它所否认的东西：“不是周三下午”不否认“周三”，“not v3”不否认“v3.1”，“not 4 GB”不否认“14 GB”，“不喜欢喝红茶”不否认“茶”。constraint 的否定是规则本身，decision 的“不做某事”是决定本身，二者不在此列。

## 两条时间轴

`valid_from/to` 是原断言的有效区间，采用 UTC 半开区间；未知保持 null。`recorded_from/to` 是此版本取得/失去 head 地位的记录时间。旧有效区间不被原地改写；`replaces_revision`、单一 head 指针和区间选择共同计算给定时点的有效版本。这保留了事后更正前系统曾知道什么，`known_at` 是额外的只读知识时间边界。

| 情况 | 写入与读取 |
|---|---|
| 明确且有来源的当前更正 | 一次事务新增版本、关闭旧记录区间、移动 head、链接证据、增加 epoch、作废旧派生工作并登记新工作 |
| 已知时间更早的迟到资料 | 留作历史版本，不因 recorded 时间更晚移动 head；as_of 可读取它明确覆盖的历史 |
| 冲突资料无法确定先后 | disputed 保留双方版本引用；排名分数不参与资格或解决冲突 |
| 未来生效 | head 保存新规则；生效前按已知区间读取旧规则，生效后使用新版本 |
| 有限例外 | 只在明确区间适用；结束后仍可回到持续有效的常规规则 |
| 当前版本有效起点未知 | 可保留明确当前断言；as_of 返回未知，不借 recorded 时间填历史 |
| 撤回 | 当前读取不回退复活旧断言；已知生效时间之前可看历史，未知撤回起点则不能推断历史有效性 |

active 表示有资格保留该断言，不代表对易变现实永久验证。工具/文档观察保留 `basis=observed` 与 `observation_at_source_time`；召回结果的条目以 `basis=observed` 标出这类观察。

## 更正接口和原文快路径

公开 revise 先执行 Schema 与 expected_revision 校验，再要求同会话最近一条已捕获人类来源支持本次更正。存在受信 recent_messages 时还需命中当前消息。旧人类引文、助手转述、未知导入不能授权新治理操作；否定、疑问（包括不带问号的问句）、条件或假设（如果、要是、万一、……的话、if、would）、举例以及他人原话或引文里的改动都不执行更正。

字符串 new_value 更正原 slot 的 value_text；受限对象允许 value_text、valid_to 和原类型的 procedure/intention/alias 字段；null 或 `{state: retracted}` 是有明确撤回原话时的撤回。条件改变形成另一个 slot，不能撤回一个自行扩大的范围。时间和替换值从支持该具体动作的句子核验，不能借同条消息另一个方案的日期。

捕获时的快路径只处理有唯一 ID/主体/属性目标、字面替换值及明确更正语义的有界表达，不等待模型或向量；过时发生时间、否定、疑问、条件或假设、未来/临时条件及不唯一目标保留原话与 unresolved_update，他人原话、举例或引文里的改动不是本人的更正，不作记录。有明确替换词（改为、改成、change to）时，替换值取它所指的值，不取“是”“用”这类可能嵌在别的词里的字（“还是改成 X”）：中文替换词之后是该分句余下的全部（含空格，去掉句末的“了”“吧”，“改成 90 天了”取“90 天”），change to/switch to 之后是一个词，标识符里的 #、@、/ 都算在值里（“#ops-pager”）。它不承诺解析所有自然语言；较复杂的提取由提炼按同一治理规则处理，不能通过另一条写入路径绕过此处约束。
