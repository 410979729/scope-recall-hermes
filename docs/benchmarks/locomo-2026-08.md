# LoCoMo benchmark receipt — August 2026

This document records a **locally executed legacy benchmark run** of the Scope Recall `1.9.2` development line. It is evidence for the numbers published in the README, not a cross-vendor ranking or a claim that the historical run passes the stricter `official_comparable_categories_1_to_4` gate added later in the same development cycle.

## Run scope

- Dataset: LoCoMo, all 10 conversations
- Questions: all 1,540 questions in categories 1–4
- Evidence mode: retrieved evidence, not oracle evidence
- Embedder: `gemini-embedding-001`
- Answerer: `gpt-5.4-mini`
- Judge: `gpt-5.4-mini`
- Query planner: `gpt-5.4-mini`
- Result coverage: 1,540 / 1,540
- Invalid / missing / unexpected: 0 / 0 / 0

## Comparability boundary

This run predates the current harness's secret-free `model-route.json` receipt, strict judge-label parser, and explicit canonical-comparability checklist. Therefore it is intentionally described as **legacy local evidence**. A future run may set `official_comparable_categories_1_to_4=true` only when every explicit check passes: canonical dataset and question hashes, canonical category composition, retrieved evidence mode, complete score/retrieval rows and metrics, and a model-route receipt.

Different public LoCoMo evaluations use materially different dataset revisions, answerers, judges, prompts, and retrieval systems. These numbers must not be used to claim a universal or cross-vendor rank.
