# Verification evidence

This directory contains two distinct classes of evidence:

- **Tracked curated evidence** is versioned intentionally for review and historical reproducibility. Tracked phase bundles and the P08 source snapshot remain in their existing locations for that purpose.
- **Ignored transient per-run receipts** are generated by local verification runs, are not curated repository history, and may be removed and reproduced as needed.

Do not assume that tracked or retained historical evidence describes the current runtime or package version. Establish current runtime and version truth from live runtime evidence, current Git evidence, and installed package evidence.
