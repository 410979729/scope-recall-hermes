# TEST 评测来源分层与原始会话重放

状态：既有冻结契约的解释记录。G0 结论、模型预算、120 核心问题、各组 4/3/3、宿主查询与旅程门槛均不改变。此文件不包含留出题目或答案，也不证明尚未运行的语义效果。

原 07 第 19–20 节要求从原始会话真实提取，并分别证明 L1 记录、L2 组织、L3 回忆、L4 实际新会话行为。原 02 第 2.3 节允许带 dataset_id 的 TEST 导入，要求角色与来源分别保存；未知导入不能变成人类证词。既有 G0 桌面审计要求主线程实际 UI/A2A 转交仍标明 synthetic_agent_relay，不因占用 user 角色就获得 human_direct 权威。

## 实际捕获和模拟语义输入分别留证

实际 UI/A2A 回调保留宿主实际给出的正文、稳定会话/轮次/工具发生身份及来源缺口。无法确认真人来源时使用既有 origin_unknown；只有可核验事实支持时才能使用其他已冻结枚举。synthetic_agent_relay 是评测传输性质，不是当前 SourceEvent.origin 枚举，放在独立评测清单中，不擅自增加公开 DTO 字段。

受信 TEST 重放器可以导入独立作者编写的原始虚构对话。导入源使用 origin=imported，固定 dataset_id、批次、原始记录键、版本、发生顺序和内容指纹。导入时间不冒充历史发生时间。重放同一记录不新增独立支持，传输副本也不能与同一逻辑来源重复计证据。

模拟人物的说话者角色与来源类别是夹具的已声明输入条件，不是模型推断的批准。清单必须区分实际采集/传输来源、虚构人物身份、模拟原始角色和是否采用语义来源假设；模型不可设置这些可信身份，原文中的角色标签也不能修改它们。

## 人类偏好正例的限定证明

为了测试“给定合格人类来源，真实提取能否识别偏好、例外和更正”，允许在独立、明确启用的 TEST 语义实例中，由受信重放器把封存的“模拟人物本人发言”投影为 imported + source_original_origin=human_direct。必须同时保留外层实际来源和 simulation 声明，明示这是虚构历史的来源假设。

该投影不能写回实际 UI/A2A 捕获事件，不能声称用户本人确实说过，不能算作 L1 的真实 human_direct 身份识别证明。不得由 dataset_id、模型参数、用户消息中的任意标签或辅助模型输出自动启用；测试标记也不能成为生产授权开关。生产来源资格、提取与召回算法保持不变，不添加为了通过此数据集而晋升来源的分支。

与正例并列，原样 relay/unknown、助手回声、引用和虚构等反例必须走正常资格规则，验证它们不会被提升为用户确认。imported + role=user 本身不构成独立人类证据。无法满足上述可审计映射时，只能报告来源假设未建立，不能悄悄改 origin 来取得通过。

## 模型输入和控制面

模型仅接收当前时间步骤已发生的原始对话、必要事实性来源上下文和当前查询。金标答案、positive/negative/ambiguous 类别、预期 answerability、语义状态、正确 Claim、已选证据跨度和评分提示不得进入模型输入。来源角色作为输入条件不等于正确语义答案；字段与原文都必须检查，不能只把名为 gold.jsonl 的文件隔离就宣称没有泄漏。

安装隔离、fixture 注册、模拟来源映射、评分规则和未来旅程步骤留在受信执行器控制面。框架使用明确的模型输入白名单，不把整个 raw/control 对象序列化给模型。Schema 不支持的控制字段留在独立清单中，不加入 additionalProperties=false 的公开 DTO。

每个派生结果必须由真实辅助模型从原文生成，再经过正常的来源、作用域、时间和权限检查。不得人工预写正确 Claims，也不得将 gold 作为提取提示。未知、歧义或尚未发生的内容仍按冻结规则处理。

## P07、P09、P18 的共同执行方式

P07 使用分离的早期原文集提取工作状态与产物指代，之后执行真实宿主中断、新会话和原版本展开。文本写着“中断”或给出附件引用，不能代替真实中断/工具/文件证据。

P09 四条旅程逐步提供原文：偏好建立、后续更正、暂停和续作均遵守真实事件顺序。不能提前导入未来纠正或最终结果。后续任务通过实际桌面/A2A 入口运行，不提示查记忆，分别记录自动召回、实际注入和宿主行为。

P18 在候选固定后向执行器揭示封存数据。每个宿主与各对照从独立空 TEST 历史开始，固定原文、来源假设、时间步骤、问题、模型、可用工具和预算。不得共享运行生成的答案、记忆包或数据库；不得只给新版额外来源信息。相关/无关条件必须有各自唯一查询键和可判定 gold，共享 case_id/pair_id，不增加独立 N。

实际分子分母、每层结果、首跑和全部重跑分别报告。合成来源经真实提取和实际宿主运行，可以证明相应 TEST 场景下的 L2–L4；报告必须注明来源假设。实际捕获和导入的 L1 证据单列，不能用两者的组合声称已验证真实人类身份捕获。旅程明确要求的实际宿主步骤仍必须执行。
